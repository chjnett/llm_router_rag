Reality check

좋은 신호와 아직 불안한 부분

연구를 계속할 이유

  • 비용 차이가 충분히 큼p50 7.27×, p95 9.27× — 선택으로 아낄 공간이 존재.
  • 품질 차이도 뚜렷함행·열 shape에서 Strong 0.964, Cheap 0.225.
  • 재실행 비용이 통제됨모든 parser output을 cache하여 평가 코드만 반복 가능.

과장하면 안 되는 부분

  • 현재 shape 지표는 GriTS가 아님셀 병합, 위치, 텍스트 내용까지 아직 공식 비교하지 않음.
  • 구조 대응은 245/30055페이지는 structure XML 대응이 없어 shape 진단에서 제외.
  • Strong native crash 경험PMC6067716 page 7을 고정 제외하고 deterministic replacement 사용.

헷갈리기 쉬운 용어

Cheap / Strong processing

Cheap은 PyMuPDF처럼 빠르고 가벼운 처리를, Strong은 Docling처럼 표 구조를 더 정교하게 분석하지만 더 오래 걸리는 처리를 뜻합니다. 모델 크기가 아니라 실제 capability와 비용으로 구분합니다.

Capability-aware routing

모든 PDF에 비싼 처리를 쓰지 않고, Cheap으로도 충분한 문서는 Cheap에 두며 어려운 문서만 Strong으로 보내는 선택 전략입니다.

GriTS

표 셀의 topology, 위치, 텍스트 내용을 grid 정렬로 비교하는 공식 구조 평가입니다. 현재 shape 진단보다 훨씬 엄격합니다.

P0 Gate가 HOLD인 이유

속도 차이와 예비 품질 차이는 확인했지만 공식 구조 품질이 아직 없기 때문입니다. 이 단계에서 라우터를 학습하면 부정확한 capability label을 학습할 위험이 있습니다.
